# 🚪 Porta de Entrada Fechada?

## 📝 Descrição do Projeto

O projeto **Porta de Entrada Fechada?** consiste em um site que aborda os impactos da inteligência artificial no mercado de trabalho, principalmente nas oportunidades de primeiro emprego para jovens da Geração Z na área de tecnologia. O objetivo principal é discutir como a automação de tarefas está mudando as vagas de nível júnior e como os jovens podem desenvolver experiência profissional e lidar com os desafios dessa transformação.

Desenvolvido como parte do curso de **Análise e Desenvolvimento de Sistemas (ADS) – UNICID (2026)**, o site apresenta informações, pesquisas, gráficos, um simulador de empregabilidade e debates sobre o futuro do mercado de trabalho na era da inteligência artificial.

## 🚀 Tecnologias Utilizadas

* **Linguagem:** HTML5 e JavaScript
* **Estilização:** CSS
* **Bibliotecas:** Bootstrap 5 e Chart.js
* **Ferramentas:** VSCode, GitHub e ferramentas de inteligência artificial
* **Hospedagem:** GitHub Pages

## 📊 Resultados e Aprendizados

O projeto permitiu desenvolver um site com diferentes páginas, apresentando informações e recursos interativos sobre os impactos da inteligência artificial no primeiro emprego.

* **Estrutura HTML:** Aprendi a criar e organizar diferentes páginas com menus de navegação e conteúdos.
* **Estilização:** Utilizei CSS e Bootstrap para personalizar cores, fontes, layouts e elementos visuais.
* **Gráficos e Dados:** Aprendi a utilizar Chart.js para apresentar pesquisas e estatísticas por meio de gráficos.
* **Interatividade:** Desenvolvi recursos em JavaScript, incluindo um simulador de empregabilidade e alternância entre modo claro e escuro.
* **Organização de Conteúdo:** Aprendi a organizar informações, pesquisas e fontes para apresentar um tema de maneira clara.
* **Desenvolvimento Web:** Aprimorei meus conhecimentos em HTML, CSS, JavaScript, Bootstrap e integração de bibliotecas durante a criação do site.

## 🧠 Declaração de Uso Ético da IA

Este projeto utilizou inteligência artificial (ChatGPT e Gemini) como ferramentas de suporte tecnológico para auxiliar na estruturação do HTML, desenvolvimento de funcionalidades em JavaScript, criação de gráficos com Chart.js, estilização com CSS e resolução de possíveis erros durante o desenvolvimento. O código gerado foi analisado, revisado e ajustado, com verificação dos dados utilizados e responsabilidade sobre o resultado final do projeto.
