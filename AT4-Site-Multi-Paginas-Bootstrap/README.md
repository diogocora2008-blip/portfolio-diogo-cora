# 🎮 História dos Videogames

## 📝 Descrição do Projeto

O projeto História dos Videogames consiste em um site que apresenta a evolução dos videogames ao longo dos anos, desde os primeiros consoles até as plataformas modernas. O objetivo principal é mostrar como a indústria dos jogos eletrônicos evoluiu, destacando consoles, gerações e acontecimentos importantes que marcaram essa história.

Desenvolvido como parte do curso de **Análise e Desenvolvimento de Sistemas (ADS) – UNICID (2026)**, o site reúne informações históricas, imagens e conteúdos organizados em diferentes páginas, permitindo que os visitantes conheçam melhor a trajetória dos videogames.

## 🚀 Tecnologias Utilizadas

* **Linguagem:** HTML5 e JavaScript
* **Estilização:** CSS
* **Biblioteca:** Bootstrap 5
* **Ferramentas:** VSCode e GitHub
* **Hospedagem:** GitHub Pages

## 📊 Resultados e Aprendizados

O projeto permitiu desenvolver um site com diferentes páginas, aplicando conhecimentos de desenvolvimento web e organização de conteúdo.

* **Estrutura HTML:** Aprendi a criar e organizar diferentes páginas com menus de navegação e conteúdos.
* **Estilização:** Utilizei CSS e Bootstrap para personalizar cores, fontes, imagens e elementos visuais.
* **Navegação:** Desenvolvi links para conectar as páginas e facilitar a navegação dos visitantes.
* **Organização de Conteúdo:** Aprendi a apresentar informações históricas e imagens de maneira organizada.
* **Desenvolvimento Web:** Aprimorei meus conhecimentos em HTML, CSS, JavaScript e Bootstrap durante a criação do site.

## 🧠 Declaração de Uso Ético da IA

Este projeto utilizou inteligência artificial (ChatGPT e Gemini) como ferramentas de suporte tecnológico para auxiliar na estruturação do HTML, estilização com CSS, utilização do Bootstrap e resolução de possíveis erros durante o desenvolvimento. Todo o código foi revisado e testado, garantindo minha responsabilidade sobre o funcionamento final do projeto.
