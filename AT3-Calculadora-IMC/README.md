# 🎬 Calculadora de IMC

## 📝 Descrição do Projeto

Este projeto consiste em uma calculadora de Índice de Massa Corporal (IMC), desenvolvida para permitir que os usuários calculem seu IMC de maneira simples e rápida. O objetivo principal é informar a classificação do peso corporal de acordo com a altura e o peso informados pelo usuário.

Desenvolvido como parte do curso de **Análise e Desenvolvimento de Sistemas (ADS) – UNICID (2026)**, o sistema utiliza uma fórmula matemática para calcular o IMC, dividindo o peso pela altura ao quadrado, apresentando o resultado e sua respectiva classificação.

## 🚀 Tecnologias Utilizadas

* **Linguagem:** HTML5 e JavaScript
* **Estilização:** CSS
* **Ferramentas:** VSCode
* **Modelo de IA:** Gemini / ChatGPT

## 📊 Resultados e Aprendizados

O projeto permite realizar cálculos de IMC de forma automática, apresentando os resultados de acordo com os dados informados pelo usuário.

* **Cálculo Automático:** Implementação da fórmula IMC = Peso ÷ (Altura × Altura).
* **Validação de Dados:** Aprendi a utilizar JavaScript para verificar as informações inseridas pelo usuário.
* **Manipulação do HTML:** Aprendi a utilizar JavaScript para capturar informações dos campos e apresentar os resultados diretamente na página.
