# 🚀 Deploy do Site Game Zone

## 📝 Descrição do Projeto

Este projeto consiste na publicação do site Game Zone na internet, utilizando a plataforma GitHub Pages. O objetivo foi aprender como disponibilizar um site desenvolvido em HTML, CSS e JavaScript para que outras pessoas possam acessá-lo por meio de um link público.

O processo envolveu a organização dos arquivos do site, criação de um repositório no GitHub e configuração da hospedagem gratuita por meio do GitHub Pages.

## 🚀 Tecnologias Utilizadas

* **Linguagem:** HTML5, CSS e JavaScript
* **Ferramentas:** VSCode e GitHub
* **Hospedagem:** GitHub Pages
* **Versionamento:** Git

## 📊 Resultados e Aprendizados

Durante a realização do deploy, aprendi como publicar um projeto web e disponibilizá-lo para acesso público.

* **Criação do Repositório:** Criei um repositório no GitHub para armazenar os arquivos do projeto.
* **Envio dos Arquivos:** Enviei os arquivos HTML, CSS, JavaScript e as imagens utilizadas no site para o repositório.
* **Configuração do GitHub Pages:** Acessei as configurações do repositório, entrei na opção Pages e selecionei a branch principal como fonte de publicação.
* **Publicação:** Após salvar as configurações, o GitHub Pages realizou a publicação e gerou um endereço para acessar o site.
* **Aprendizado:** Compreendi como funciona a hospedagem de sites e como disponibilizar projetos gratuitamente na internet.

## 🧠 Declaração de Uso Ético da IA

Este projeto utilizou inteligência artificial (ChatGPT e Gemini) como ferramentas de suporte para auxiliar na compreensão do processo de publicação, organização dos arquivos e resolução de possíveis dificuldades durante a configuração do GitHub Pages. As etapas foram acompanhadas e verificadas por mim.
